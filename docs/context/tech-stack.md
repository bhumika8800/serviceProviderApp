# Project Tech Stack

This document outlines the standard technology stack utilized for the ServiceProviderApp project.

## Frontend
- **Framework:** React Native

## Backend
- **Framework:** Node.js with Express

## Database
- **Engine:** MongoDB

## Authentication
- **Service:** Firebase

## Notifications
- **Service:** Firebase

## Payments
- **Gateway:** Razorpay

## Image Storage
- **Service:** Cloudinary

## Version Control
- **Platform:** GitHub
